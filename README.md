# Geometric Lib

## Общее описание решения
Библиотека `geometric_lib` предназначена для базовых геометрических расчетов на Python.
Включает функции для вычисления площади и периметра следующих фигур:
- Круг (`circle.py`)
- Квадрат (`square.py`)
- Прямоугольник (`rectangle.py`)
- Треугольник (`triangle.py`)

## Описание функций

### 1. circle.py
- `area(r)`
  - Принимает: `r` (`int` / `float`) — радиус круга.
  - Возвращает: `float` — площадь круга по формуле `S = pi * r**2`.
  - Пример вызова: `area(5)` -> `78.5398`
- `perimeter(r)`
  - Принимает: `r` (`int` / `float`) — радиус круга.
  - Возвращает: `float` — длину окружности по формуле `P = 2 * pi * r`.
  - Пример вызова: `perimeter(5)` -> `31.4159`

### 2. square.py
- `area(a)`
  - Принимает: `a` (`int` / `float`) — сторона квадрата.
  - Возвращает: `int` / `float` — площадь квадрата по формуле `S = a**2`.
  - Пример вызова: `area(5)` -> `25`
- `perimeter(a)`
  - Принимает: `a` (`int` / `float`) — сторона квадрата.
  - Возвращает: `int` / `float` — периметр квадрата по формуле `P = 4 * a`.
  - Пример вызова: `perimeter(5)` -> `20`

### 3. rectangle.py
- `area(a, b)`
  - Принимает: `a` (`int` / `float`), `b` (`int` / `float`) — стороны прямоугольника.
  - Возвращает: `int` / `float` — площадь прямоугольника по формуле `S = a * b`.
  - Пример вызова: `area(3, 4)` -> `12`
- `perimeter(a, b)`
  - Принимает: `a` (`int` / `float`), `b` (`int` / `float`) — стороны прямоугольника.
  - Возвращает: `int` / `float` — периметр прямоугольника по формуле `P = 2 * (a + b)`.
  - Пример вызова: `perimeter(3, 4)` -> `14`

### 4. triangle.py
- `area(a, h)`
  - Принимает: `a` (`int` / `float`) — сторона треугольника, `h` (`int` / `float`) — высота.
  - Возвращает: `float` — площадь треугольника по формуле `S = a * h / 2`.
  - Пример вызова: `area(6, 4)` -> `12.0`
- `perimeter(a, b, c)`
  - Принимает: `a`, `b`, `c` (`int` / `float`) — длины трех сторон треугольника.
  - Возвращает: `int` / `float` — периметр треугольника по формуле `P = a + b + c`.
  - Пример вызова: `perimeter(3, 4, 5)` -> `12`
